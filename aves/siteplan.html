Aves de Chile

Individual Project Site Plan — WDD 231

1. Site Name

Aves de Chile

This name was chosen because it directly and clearly identifies the subject of the site in the language most associated with the content: Chilean birds. It is short, memorable, and easy to pronounce for both Spanish and English speaking visitors.

Optional domain availability: avesdechile.cl

2. Site Purpose

The site is an informational guide showcasing native and endemic Chilean bird species. It provides a home page introducing the topic, a catalog page displaying a collection of birds pulled from a data source with details such as common name, scientific name, habitat, size, conservation status, and region, and a page with a form where visitors can report bird sightings. Visitors can also save favorite birds using local storage and view detailed information about each species in a modal dialog.

3. Scenarios

  • What endemic bird species can I expect to see if I go hiking in central Chile?
  • How do I report a bird sighting I observed during a recent trip?
  • Which of these species are currently considered threatened or endangered?

4. Color Scheme

Forest Green — #2f4d3a

Used for the header background, headings, and navigation.

Sky Blue — #6fa8c9

Used for links, buttons, and small accent details.

Warm Sand — #f5f1e6

Used as the main page background color.

Charcoal — #2b2b2b

Used for body text to ensure readability against light backgrounds.

5. Typography

Merriweather (serif) will be used for all headings (h1–h3), giving the site an editorial, field-guide feel. You can see it applied to every heading on this page.

Lato (sans-serif) will be used for all body text, paragraphs, and list items, for clean readability on both mobile and desktop screens. This paragraph itself is set in Lato.
